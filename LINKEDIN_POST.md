Lançando **LivroAI** 📚✨

Sempre quis uma forma automática de descobrir novos livros analisando minha estante? 

Essa é a ideia por trás do **LivroAI** - uma plataforma que usa **visão computacional** + **IA** para:

📷 Fotografar sua estante
🤖 Detectar automaticamente todos os livros (YOLO)
🔎 Ler títulos nos livros (Google Vision OCR)
💡 Gerar recomendações personalizadas (Mistral LLM)
📚 Manter histórico de análises com segurança

**Stack:**
- Backend: FastAPI + SQLAlchemy async
- Database: Supabase PostgreSQL
- Frontend: React 18 + Vite
- ML: YOLO (HF Space) + Google Vision + Mistral
- Deploy: Vercel (Python + React)

**Features principais:**
✅ Análise em ~30-60s
✅ Histórico com sessões seguras (token)
✅ Interface luxury design (mobile-first)
✅ Catálogo pessoal com filtros
✅ CORS protegido + request IDs para debugging

**Aprendizados principais:**
1️⃣ Arquitetura async em FastAPI reduz latência em pipelines I/O-heavy
2️⃣ Token-based session é mais simples que JWT para casos sem persistência de usuário
3️⃣ Middleware ordering no FastAPI importa (CORS antes de logging!)
4️⃣ Batch DB operations vs individual flushs = 3-5x mais rápido
